# Cours de Programmation en JavaScript

## Introduction

Bienvenue dans ce cours de programmation en **JavaScript** !  
Ce cours est conçu pour les débutants qui souhaitent apprendre les bases du langage JavaScript, l’un des langages les plus populaires pour le développement web et au-delà.

## Objectifs du Cours

À la fin de ce cours, vous serez capable de :

- Comprendre les concepts fondamentaux de la programmation en JavaScript.
- Écrire des scripts simples pour interagir avec une page web.
- Utiliser les structures de contrôle (conditions, boucles, etc.).
- Manipuler des tableaux et des objets.
- Travailler avec des fonctions et comprendre les notions de portée.
- Utiliser le DOM pour manipuler le contenu HTML.
- Gérer les événements et interagir avec l’utilisateur.
- _à venir…_

## Prérequis
- Connaissances de base en informatique et navigation web.
- Aucune expérience préalable en programmation n’est requise.

## Projets et exercices
Le cours proposera des exercices de niveaux différents, chacun sera accompagné de sa correction.  
Pour consolider les acquis, des _projets_ seront proposés. Ils viseront à appliquer JavaScript à des cas concrets, souvent liés à des domaines variés :
- Web interactif
- Jeux simples
- Visualisation de données
- Mathématiques x JavaScript
- IRL x JavaScript
