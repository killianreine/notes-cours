# Qu'est-ce que JavaScript

JavaScript est né en 1995 pour permettra d'ajouter des programmes ans les sites web du navigateur *Netscape Navigator*. Il a depuis été adopté par tous les autres navigateurs modernes. Il a rendu possible la création d'application web modernes, qui permettent d'interagir avec l'utilisateur sans avoir besoin de recharger la page à chaque action. 

Après que JavaScript ai été adopté par les navigateurs modernes, un document standard a été écrit, il s'agit de l'**ECMAScript** qui permet de décrire comment utiliser le langage JavaScript pour que chaque navigateur qui prétendait prendre en compte le JS puisse s'assurer qu'ils fournissent le même langage.

>[!note]
>L'ECMAScript et le JavaScript désigne le même langage ils peuvent donc être utilisés de manière similaire.
