# Introduction
## Qu'est-ce que JavaScript

JavaScript est né en 1995 pour permettra d'ajouter des programmes ans les sites web du navigateur *Netscape Navigator*. Il a depuis été adopté par tous les autres navigateurs modernes. Il a rendu possible la création d'application web modernes, qui permettent d'interagir avec l'utilisateur sans avoir besoin de recharger la page à chaque action. 

Après que JavaScript ai été adopté par les navigateurs modernes, un document standard a été écrit, il s'agit de l'**ECMAScript** qui permet de décrire comment utiliser le langage JavaScript pour que chaque navigateur qui prétendait prendre en compte le JS puisse s'assurer qu'ils fournissent le même langage.

>[!note]
>L'ECMAScript et le JavaScript désigne le même langage ils peuvent donc être utilisés de manière similaire.

## Les versions
Il y a eu plusieurs versions de JavaScript. ECMAScript version 3 était la version largement soutenue lors de l'ascension de JavaScript à la domination, environ entre 2000 et 2010. Au cours de cette période, des travaux sont en cours sur une version 4 ambitieuse, qui prévoit un certain nombre d'améliorations radicales et d'extensions à la langue.
Changer un langage vivant, largement utilisé de manière aussi radicale s'est avéré politiquement difficile, et les travaux sur la version 4 ont été abandonnés en 2008. Une version 5, beaucoup moins ambitieuse, qui n'a fait qu'apporter quelques améliorations non controversées, est sortie en 2009. En 2015, la version 6 est sortie, une mise à jour majeure qui incluait certaines des idées prévues pour la version 4. Depuis lors, nous avons eu de nouvelles petites mises à jour chaque année.
