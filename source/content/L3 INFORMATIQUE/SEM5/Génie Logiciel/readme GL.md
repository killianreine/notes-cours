# 💻 Cours de Génie Logiciel

Bienvenue ! Ce dépôt contient un cours complet de Génie Logiciel, destiné aux étudiants en informatique ou à toute personne souhaitant comprendre comment concevoir et maintenir des logiciels de qualité.

## 🎯 Objectifs
- Comprendre le cycle de vie d’un logiciel
- Apprendre les bonnes pratiques de conception et de développement
- Maîtriser les méthodes de gestion de projet logiciel
- Développer un code propre, maintenable et évolutif
